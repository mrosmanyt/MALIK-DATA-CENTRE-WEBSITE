## What is a Windows retail key?

A retail key is a 25-character product key that activates one Windows edition on your PC. It is written as five groups of five letters and numbers, separated by dashes.

Microsoft describes two ways to activate Windows: a **digital license**, which is tied to your hardware and Microsoft account, and a **product key**, which you type in yourself. A retail key is the second type. Once Windows accepts a valid key, your device also gets a digital license for that edition, so you usually do not need to type the key again after a clean reinstall of the same edition on the same PC.

The key must match the edition. A Windows 11 Pro key activates Windows 11 Pro. It does not activate Windows 11 Home, and a Home key will not activate Pro.

## How to activate Windows 11 Pro with a retail key

If your PC already runs Windows 11 Pro but is not activated, follow these steps:

1. Select the **Start** button and open **Settings**.
2. Go to **System**, then **Activation**.
3. Next to **Change product key**, select **Change**.
4. If the User Account Control window appears, select **Yes** (or enter an administrator password).
5. Type the 25-character Windows 11 Pro key exactly as you received it.
6. Select **Next**, then **Activate**.
7. Wait for the confirmation. The Activation page should now say Windows is activated.

Once it is done, the watermark disappears, usually right away or after a restart, and personalisation options like wallpaper and colours are unlocked.

## How to upgrade Windows 11 Home to Pro with a key

Most laptops sold in Pakistan come with Windows 11 Home. You can move to Pro without reinstalling anything by entering a Pro key on the same Activation page.

Microsoft's own guidance says the manual upgrade is meant for devices running an **activated** copy of Windows 11 Home, so check your activation state first.

1. Open **Settings**, then **System**, then **Activation**, and confirm the edition says Windows 11 Home.
2. Next to **Change product key**, select **Change**.
3. Enter the 25-character Windows 11 Pro key.
4. Select **Next** to start the upgrade.
5. Save your open work. Windows prepares the upgrade and restarts your PC.
6. After the restart, go back to the Activation page. The edition should now show Windows 11 Pro.

Your files, apps and settings stay in place during this edition upgrade. It is still smart to back up important files first, especially on a work laptop.

> Pro adds features Home does not have, including BitLocker drive encryption, Remote Desktop and the ability to join a work domain or Microsoft Entra ID, according to Microsoft.

## How to link your license to your Microsoft account

Linking your license to a Microsoft account makes it easier to reactivate Windows later, for example after a motherboard change. It takes one minute:

1. Make sure you are signed in to Windows with a Microsoft account (an email address shows above "Administrator" in Your info).
2. Go to **Settings**, then **System**, then **Activation**.
3. If you see **Add an account**, select it and sign in.

When it works, the Activation page says Windows is activated with a digital license linked to your Microsoft account. If you replace major hardware later, you can use the Activation troubleshooter to reactivate.

## What if Windows 11 activation fails?

Most activation problems come from a small number of causes, and each has a simple fix:

- **Typing mistake.** Check for similar-looking characters such as 8 and B, or 0 and O. Copy and paste the key if you received it as text.
- **Wrong edition.** A Pro key will not activate Home through a reinstall. Either upgrade with the steps above or install the Pro edition.
- **No internet.** Connect and try again, then restart the PC.
- **Not an administrator.** Sign in with an administrator account before changing the key.
- **Error code on screen.** Note the exact code and send us a screenshot on WhatsApp. Microsoft also has a help page for activation errors.
