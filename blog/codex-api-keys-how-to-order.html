A key is not a chat account and not an editor

If a person needs to type in a website and read answers, they do not need a Codex API key. They need a subscription.

  • ChatGPT Go is the budget chat plan on this store, from Rs 2,200 for 6 months on a shared account, or Rs 2,900 for 3 months on a ready-made account. It is not named ChatGPT Plus.
  • Cursor Pro is the desktop editor, Rs 4,200 for 1 month or Rs 21,000 for 12 months on a private account. The Cursor price guide is that table. Cursor can call models inside the editor. That usage is not the same object as a Codex API key you paste into your own server.

Buy the API pack when your code, a script, or a product will call Codex. Buy the chat plan when a person will use a website. Buy Cursor when a developer will edit a repository. Mixing those up is why someone asks for "Codex" and then cannot log in at chatgpt.com. The key is a credential. It is not a password for the chat site.

The developer tool guide sorts Cursor, Replit, Lovable, and Bolt, which have public rupee prices. Codex stays off that price table on purpose.

How to order without paying the wrong amount

  1. Open the Codex API page and copy the pack name, the size, and the duration. Use the words on the row, not a nickname.
  2. Message WhatsApp +92 344 5739206. Say you need an API key, not a chat login. Paste the pack name.
  3. Wait for the amount. In Pakistan, pay only after that message, with EasyPaisa, JazzCash, NayaPay, UPaisa, Meezan Bank or bank transfer. Outside Pakistan, pay in USDT via Binance on BEP20 or TRC20 after we confirm the amount in your currency.
  4. Do not pay a number you saw on a forum, in an old chat, or next to a dollar size on the pack. The dollar size is not the invoice.
  5. The delivery policy says most orders are ready within 5–30 minutes after payment is confirmed. A bank transfer can take longer to show than a wallet payment. The key arrives on WhatsApp.
  6. Store the key outside the chat. Do not commit it to a public repository, do not paste it into a screenshot you post, and do not email it to a group. A leaked key can spend the credit.
  7. Make one small call the same day. If the key is rejected or the size is not the pack you named, screenshot the error while the warranty on that pack still applies. The spec line says full warranty. The refund policy covers a plan we cannot deliver on the terms we confirmed.

We will not ask for the password of your personal email. The key, once delivered, is a secret in the same way a password is. If you rotate it, the old key stops. Plan for that before you hard-code it in a place you cannot change.

What to check on day one

The useful test is one authenticated call that spends a tiny amount of the pack, then a look at whatever balance the provider shows. Write down the pack name you ordered next to that screenshot. 1 day and 14 days go by quickly. A month of Astra6 is longer, and it is still a dated window, not a permanent key.

Do not build the production launch on the last hour of a 1-day pack. If the job needs 14 days, order the 14-day row. If the job needs a month, order an Astra6 size and wait for the quote. Upgrading later is a new order, not an automatic extension.

We do not print how many requests a million credits represent. The provider's own usage meter is the source. Anyone who promises a fixed number of agent runs per pack is not quoting this catalog.

Keep the payment screenshot with the key-delivery message. If you must delete the key from the chat after you have stored it safely, keep the payment proof. Support can match an order faster with that file than with a paraphrase of the amount.
