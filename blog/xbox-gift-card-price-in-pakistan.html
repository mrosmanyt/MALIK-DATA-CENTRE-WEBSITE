Xbox codes and Game Pass

Game Pass is Microsoft's subscription library: pay for the month, play the games in the library while the month lasts. An Xbox gift card and a Game Pass month are related but not identical — a gift card adds balance to your Microsoft account, which you can spend on games, add-ons or a subscription, while a 1-month code is time on a plan.

That is why the two rows exist side by side. The voucher is balance-shaped: a code you redeem and spend. The 1-month plan is time-shaped: a code that covers a month. If your only goal is "play Game Pass games this month", say so in the first WhatsApp message and ask the team to confirm the 1-month code covers it. Do not assume a voucher equals a Game Pass month, and do not pay Rs 1,800 expecting a named Game Pass Ultimate tier the catalog does not print. The Xbox Gift Codes page lists both rows with their prices; the WhatsApp confirmation is what turns the row into the exact product you want.

How to redeem an Xbox code

Redeeming takes about two minutes, and you should do it while the WhatsApp chat is still open so any problem is caught the same day.

  1. Sign in to the Microsoft account you actually play on. A code redeemed on the wrong account is spent — it cannot be moved to another account afterwards.
  2. Open the redeem page at microsoft.com/redeem, or redeem on the console from the Store.
  3. Enter the 25-character code exactly as delivered, and confirm.
  4. Check the result on screen: the balance added, or the month showing as active. Screenshot that screen the same day.

One warning before you pay: Xbox codes can be region-sensitive, so confirm on WhatsApp that the code matches your account's region. A code for the wrong region is the one problem a screenshot cannot fix after redemption, and it is the question that costs nothing to ask first.
