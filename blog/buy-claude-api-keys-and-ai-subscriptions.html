A key is not a chat account

If you want to type in a website and get answers, you do not need an API key. You need a subscription:

Buy the API pack when your own code, n8n flow or product will call the API. Buy the chat plan when a person will use the website. Mixing those up is the usual reason a buyer asks for a “Claude login” and receives a key they cannot paste into claude.ai.
